# Temporal Beacon Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.5] - 2024-01-13

### Changed
- Migrated to standalone open-source project
- Updated build system from Nx to standard npm scripts
- Improved documentation and added contributing guidelines
- Added comprehensive CI/CD workflows

### Added
- Add support for enums and fix optional in Input
- GitHub Actions CI/CD pipeline
- Automated testing and coverage reporting
- ESLint and Prettier configuration
- Issue and PR templates
- Code of Conduct and Security Policy
- Dependabot configuration

## [1.0.0] - Initial Release

- Initial release of Temporal Beacon
- Service discovery for Kubernetes clusters
- Temporal workflow and activity visualization
- Material-UI based web interface
- CLI tool for easy execution
